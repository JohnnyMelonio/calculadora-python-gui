# 🧮 Calculadora Python GUI

Projeto de uma calculadora desktop desenvolvida em **Python** com interface gráfica usando **Tkinter**.

O projeto foi criado como praticas de python simples para demonstrar conhecimentos em Python, programação orientada a objetos, eventos de interface gráfica e organização de código.

## 🚀 Funcionalidades

- Operações de adição
- Subtração
- Multiplicação
- Divisão
- Porcentagem
- Números decimais
- Botão para limpar a expressão
- Botão para apagar o último caractere
- Suporte ao teclado
- Tratamento de erros matemáticos
- Interface gráfica responsiva dentro da janela

## 🛠️ Tecnologias

- Python 3
- Tkinter
- Programação Orientada a Objetos
- Git/GitHub

## 📋 Pré-requisitos

Tenha o Python 3 instalado.

O Tkinter normalmente já acompanha a instalação do Python no Windows.

## ▶️ Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU-USUARIO/calculadora-python-gui.git
```

Entre na pasta:

```bash
cd calculadora-python-gui
```

Execute:

```bash
python calculadora.py
```

## ⌨️ Atalhos

| Tecla | Ação |
|---|---|
| `Enter` | Calcular |
| `Esc` | Limpar |
| `Backspace` | Apagar |
| `0-9` | Números |
| `+ - * / %` | Operadores |
